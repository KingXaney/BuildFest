## Run it in 30 seconds (no installation)

1. Open `index.html` in Chrome, Edge or Firefox.
2. Explore the built-in results, or press **Load survey file** and choose a `.csv` or `.xlsx`. The provided dataset works as is.
3. Open **Can you trust it?** and press **Run the checks now**. The tool tests itself in your browser, including 65 core results against a separate R program.
